## 一、准备工作

- 浏览器：Edge / Chrome / Firefox 均可
- 服务端地址：你自己的代理服务，例如 `https://你的域名`（本地调试可用 `http://localhost:3000`）
- 已注册学习通等网课平台账号

服务端部署方式见 [README](../README.md)。

## 二、安装 Tampermonkey

### Edge

1. 打开 Edge 加载项商店：[Tampermonkey](https://microsoftedge.microsoft.com/addons/detail/tampermonkey/iikmkjmpaadaobahmlepeloendndfphd)
2. 点击「获取」→「添加扩展」
3. 点击地址栏右侧的拼图图标，把 Tampermonkey 固定到工具栏

### Chrome

1. 打开 Chrome 应用商店：[Tampermonkey](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo)
2. 点击「添加至 Chrome」
3. 如果脚本不运行：进入 `chrome://extensions` → Tampermonkey「详情」→ 打开「允许用户脚本」（Chrome 138+ 需要）

### Firefox

1. 打开 [Tampermonkey for Firefox](https://addons.mozilla.org/zh-CN/firefox/addon/tampermonkey/)
2. 点击「添加到 Firefox」

安装完成后，浏览器工具栏会出现 Tampermonkey 图标。

## 三、导入 OCS 5.2.7 脚本

### 方式 A：从本项目 Release 安装（推荐）

1. 打开 [本项目 Release](https://github.com/ceshiy/ocs-llm-assistant/releases/latest)
2. 按需下载其中一个（二选一，不要同时安装）：
   - `ocs.user.js`：标准版，自建题库需要手动添加 `@connect`
   - `ocs-universal.user.js`：全域名通用版，已内置 `// @connect *`，任意自建域名/IP 可直接使用
3. Tampermonkey 会自动弹出安装页面，点击「安装」

### 方式 B：从 OCS 官方发布页安装

1. 打开 [OCS 5.2.7 发布页](https://github.com/ocsjs/ocsjs/releases/tag/5.2.7)
2. 点击 `ocs.user.js` 下载
3. Tampermonkey 会自动弹出安装页面，点击「安装」

### 方式 C：从本仓库导入

1. 打开仓库中的 `OCS 网课助手-5.2.7.js`（或 `OCS 网课助手-5.2.7-全域名通用版.js`）
2. 点击「Raw」，全选复制
3. 点击 Tampermonkey 图标 →「管理面板」→ 左上角「+」新建脚本
4. 删除编辑器里的模板内容，粘贴刚复制的代码，按 `Ctrl + S` 保存

> 仓库里的文件名不是 `.user.js`，Tampermonkey 不会自动弹出安装页，所以需要用粘贴或「实用工具 → 从文件导入」的方式。本项目 Release 的 `ocs.user.js` / `ocs-universal.user.js` 可以直接一键安装。

### 验证安装

- Tampermonkey 管理面板中出现「OCS 网课助手」，版本为 `5.2.7`，状态为「已启用」
- 打开学习通课程页面，页面右下角出现 OCS 悬浮按钮

## 四、配置题库

1. 标准版需要先按「自建服务：添加 @connect」把服务域名加入油猴脚本；使用全域名通用版可跳过此步
2. 浏览器访问 `https://你的域名/api/config`，复制返回的 JSON（以 `[` 开头、`]` 结尾）
3. 打开 OCS 悬浮窗 →「设置」→「题库配置」（不同版本可能显示为「题库」）
4. 添加题库，选择手动配置/编辑 JSON，粘贴完整内容并保存
5. 如果使用多个题库：按相同格式在 JSON 数组中追加，token 使用自己的，不要外传
6. 保存时如果出现「图片题优化」提示，本配置已支持，可确认继续；如果出现「可疑代码」警告，确认来源可信后再继续

### 自建服务：添加 @connect

OCS 脚本默认只允许访问 `enncy.cn`、`icodef.com`、`ocsjs.com`、`zaizhexue.top`、`localhost`、`127.0.0.1`、`aliyuncs.com`。使用自建服务时，必须在脚本头部加入你的域名或公网 IP，否则 `GM_xmlhttpRequest` 会被 Tampermonkey 拦截或弹窗询问。

1. Tampermonkey 管理面板 →「OCS 网课助手」→「编辑」
2. 在 `// @connect` 区域追加（不要带 `https://`、端口和路径）：
   ```js
   // @connect     你的域名
   // @connect     你的公网IP
   ```
   例如：
   ```js
   // @connect     ocs.example.com
   // @connect     1.2.3.4
   ```
3. `Ctrl + S` 保存，刷新课程页面后重新答题
4. 如果服务使用 HTTPS 但证书不受信任，在 Tampermonkey 设置中允许无效证书，或换成受信任的证书（如 Let's Encrypt）

> 添加的主机名要与题库配置中的 URL 一致：例如配置里是 `https://ocs.example.com/api/proxy`，就加 `ocs.example.com`。也可以写成 `// @connect *` 允许所有域名（本项目 Release 的「全域名通用版」已内置），但范围太大，请仅在信任脚本来源时使用。`@connect` 匹配的是主机名，不需要写端口；`localhost` 和 `127.0.0.1` 已默认包含。

### 建议设置

| 设置项 | 建议值 | 说明 |
|---|---|---|
| 搜题最大耗时 | 60 秒 | 推理模型偶尔需要 10–20 秒 |
| 答题并发数 | 3–5 | 单题库保持 1 也完全够用 |
| 图片题优化 | 开启 | OCS 5.1+ 支持浏览器端 base64 直传 |
| 自动答题 | 按需 | 考试场景请谨慎 |

## 五、开始答题

1. 打开学习通课程、作业或考试页面
2. 点击 OCS 悬浮按钮 →「开始答题」
3. 等待气泡显示答案，确认后自动填写
4. 不要同时打开多个课程页面，避免并发过高和答案串题

## 六、常见问题

- **脚本没反应**：检查 Tampermonkey 是否启用、脚本是否启用、页面是否已刷新；Chrome/Edge 检查「允许用户脚本」；广告拦截插件可能拦截。
- **题库连接失败/跨域错误**：检查脚本头部的 `@connect` 是否包含你的服务域名或公网 IP；修改后保存并刷新页面。
- **题库请求超时**：把「搜题最大耗时」调到 60 秒；访问 `https://你的域名/health` 确认服务正常；多题库时慢题库也会拖长整体等待。
- **429 Too many pending requests**：并发太高，把答题并发数降到 3–5。
- **图片题答错**：确认已开启图片题优化，且 `LLM_VISION_MODEL` 配置的是支持 vision 的模型。
- **提示题库配置不能为空**：JSON 没有保存成功，重新粘贴完整内容。
- **出现可疑代码警告**：handler 中含网络/DOM 操作时会出现；只导入自己信任的配置。

## 七、安全提示

- LLM API Key 只放在服务端 `.env`，不要写进油猴脚本
- 题库配置中的 token 不要发到公开仓库或群聊
- 公网代理存在被他人滥用的风险，建议加访问控制或 IP 白名单
